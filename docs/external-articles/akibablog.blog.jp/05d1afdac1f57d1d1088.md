# 劇場版 たまこラブストーリーBD発売　「何度観ても心が温まります」

[![たまこラブストーリー](/media/external-articles/akibablog.blog.jp/05d1afdac1f57d1d1088/ec372f0de498-84a30593.jpg)](https://2014oct.akibablog.net/images/10/tamakolovestory/101.html)
[「たまこまーけっと」](http://tamakomarket.com/)の劇場版[「たまこラブストーリー」BD](http://www.amazon.co.jp/gp/product/B00LNCTX48/ref=as_li_ss_sm_ld_asin_tl?ie=UTF8&camp=1207&creative=13031&creativeASIN=B00LNCTX48&linkCode=shr&tag=akibablog-22)【AA】が9日に発売になった。[製品情報](http://tamakolovestory.com/product/?cat=1#/pkgMovie/001)によると本編ディスク、ブックレット、絵コンテ集などが付き、[とら秋葉原店BのPOP](https://2014oct.akibablog.net/images/10/tamakolovestory/201t.html)は『物語が完結したことはもちろんですが、純粋にステキな映画でした。何度観てもいやされて心が温まります』とかでオススメしてた。

TVアニメ[「たまこまーけっと」](http://tamakomarket.com/)の劇場版[「たまこラブストーリー」BD](http://www.amazon.co.jp/gp/product/B00LNCTX48/ref=as_li_ss_sm_ld_asin_tl?ie=UTF8&camp=1207&creative=13031&creativeASIN=B00LNCTX48&linkCode=shr&tag=akibablog-22)【AA】が、9日に発売になった。

アニメ『たまこまーけっと』は、[AV Watch](http://av.watch.impress.co.jp/docs/news/20140710_657289.html)によると『生まれ育った商店街を愛する、餅屋の娘・北白川たまこが主人公。そんな彼女のところに、人の言葉を話す高飛車な鳥が襲来し、居候する事に。たまこと不思議な鳥が繰り広げる日常が展開する』というお話で、[劇場版アニメ「たまこラブストーリー」](http://tamakolovestory.com/)は『完全新作の劇場版。春。高校3年生に進級しても北白川たまこの頭の中は相変わらずおもちのことばかり。～周りの色んなことが変わっていって、少しずつ、少しずつ、たまこの心は揺れ始める…（[※](http://av.watch.impress.co.jp/docs/news/20140710_657289.html)）』になってる。

[「たまこラブストーリー」BD](http://www.amazon.co.jp/gp/product/B00LNCTX48/ref=as_li_ss_sm_ld_asin_tl?ie=UTF8&camp=1207&creative=13031&creativeASIN=B00LNCTX48&linkCode=shr&tag=akibablog-22)【AA】のパッケージ謳い文句は『近くて遠い、ふたりの恋』で、[製品情報](http://tamakolovestory.com/product/?cat=1#/pkgMovie/001)によると本編BD、舞台挨拶映像や、ノンクレジットOP＆EDなどの映像特典、キャストコメンタリー・スタッフコメンタリーの音声特典、ブックレット、絵コンテ集、カード、しおりが付いてるみたい。

発売日のアキバでは、ポスターや『近くて遠い、ふたりの恋。京都アニメーションが贈るピュアなラブストーリー！』や、パッケージ内容のサンプルも出ていて、[とらのあな秋葉原店B](http://www.toranoana.jp/)では『もちぞーとお話したいな…"たまこラブストーリー"買ってね！デラちゃん！』[POP](https://2014oct.akibablog.net/images/10/tamakolovestory/200t.html)や、[糸電話](https://2014oct.akibablog.net/images/10/tamakolovestory/202t.html)などで展開した「たまこラブストーリー」コーナーができてた。

> 2013年3月27日の最終回から早一年…「たまこちゃんともち蔵の関係はこのままなの？ねえ！だれか教えてうああああ（頭抱え）」となった方は少なくないはず…私もです。それが！！この劇場で！！うあああああ。物語が完結したことはもちろんですが、純粋にステキな映画でした。
> 何度観てもいやされて心が温まります。
>
> 見逃してしまった、もう一度観たい、つらい時さびしい時、たまこちゃんもち蔵に会いたい、どんな時でも心を満たしてくれる。それがこのたまこラブストーリーです　 [とらのあな秋葉原店BのPOP](https://2014oct.akibablog.net/images/10/tamakolovestory/201t.html)

なお、[「たまこラブストーリー」BD](http://www.amazon.co.jp/gp/product/B00LNCTX48/ref=as_li_ss_sm_ld_asin_tl?ie=UTF8&camp=1207&creative=13031&creativeASIN=B00LNCTX48&linkCode=shr&tag=akibablog-22)【AA】の感想には、[金野秀彦さん](https://twitter.com/konno/status/520364826942398464)『感度が高く細やか。可愛らしさや気持ちの揺れや禁忌な心理への高感度カメラみたいな。やっぱり独特』、[進歩したい日記さん](http://d.hatena.ne.jp/julity/20141010)『ド直球なまでの王道ラブストーリーなんだけど、それを美麗な映像でここまでノスタルジックに、かつ映える作品に仕上げるとは…。さすがは京アニさんだわ』などがある。
