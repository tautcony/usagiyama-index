## [山田尚子とソフィア•コッポラ](https://shine.web.wox.cc/blog/entry14.html)

どうもオーウェンです。今日は山田尚子さんとソフィア•コッポラ姉さんについて書いてみようかなと思います。
ちなみに試験とかあるので、結構あっさり目な紹介です。
でも意外と引用してくる、もっと言えばうまくパクってくるとはこういうことか！とShinEの参考になるはずです。

多分世間的な知名度や映画ファン的な知名度は余裕で「ソフィア•コッポラ&gt;山田尚子」だと思います。なにしろコッポラの娘でアカデミー賞などなど世界的にも評価されていますからね。
しかしいきなりこれがアニメオタクになると「山田尚子&gt;&gt;&gt;&gt;&gt;&gt;&gt;&gt;ソフィア•コッポラ」になるという。
知らない人に紹介すると、山田尚子さんは「けいおん!」の監督です。まだ20代なのに「けいおん！」で大フィーバーしたので末恐ろしいですね。（更にここには載せませんが、結構可愛いと評判です）
というか書き出したら止まらないからここらでザクッと本題に行きますね。
確か前にtwitterでも書いたと思いますが、山田監督が好きな映画監督でソフィア•コッポラをあげてたんですね。そこでその影響をザックリ見てみましょう。
まずはソフィア•コッポラ初監督作品の「ヴァージン•スーサイズ」の予告をご覧ください。

続きまして、山田監督は内田真礼（a.k.aまあやお姉さん）が主演声優を務める「中二病でも恋がしたい！」のEDの絵コンテ•演出を担当されています。
ここでは2期の「中二病でも恋がしたい!戀」のEDを見てみましょう。

はい！どうせ見てないでしょ？笑
だからザックリと画像で紹介しちゃうYO！

ソフィア•コッポラはとにかく女子人気がすごいらしいんですが、
「けいおん！」も女子人気が高いらしいですね

この辺が関係しているんじゃないですかね（ザックリ）

引用するとか影響されて自分の表現に出すってすごいざっくりとしてるけどこんな感じなのではないでしょうかねという紹介でした。
