【明日香手中的“伪装”】

![](/media/notes/504870376/p27537192.jpg)

重温第一集可以发现，明日香用假手送糖欢迎新生的情节是在暗喻明日香是个善于伪装的人。假手这个捉弄人的道具象征明日香的“伪装”。

![](/media/notes/504870376/p27537193.jpg)

上集中明日香用瓶装水捉弄久美子，当久美子追问明日香的个人看法时，明日香放下了手中的那瓶水（=卸下伪装），道出了真心话，说罢又拿起那瓶水离去。

![](/media/notes/504870376/p27537194.jpg)

本集中的这个场景与上集形成了对比。香织让明日香评价她的独奏时，明日香扔给香织一瓶汽水，但正在练习的香织是不便喝汽水的（因为会打嗝）。然后明日香拿起了自己的那瓶汽水，开玩笑地说要不要来个香槟式的庆祝，接着像是回避香织的问题般拿着这瓶水起身离开。这个场景中的瓶装水同样是捉弄对方的道具，面对香织的反复追问，明日香先用“伪装”搪塞，最后又在伪装中道出真实。
第一集中的假手、上集与本集中的瓶装水，都是用来表现明日香的“伪装”的小道具。
【优子手中的“决心”】

![](/media/notes/504870376/p27537195.jpg)

优子用左手抓住久美子询问她的看法。“一年级就能吹出这样的乐声，太不公平了，简直是犯规”——说完这句话后，优子放开了久美子的手。“放手”这个象征性的动作代表优子承认了丽奈的实力，她对香织通过实力取胜这条路感到无望。

![](/media/notes/504870376/p27537196.jpg)

站在鞋柜前的优子与回忆中一年级的优子站在教室门前的叠印镜头。教室门内是香织当初恳求三年级学姐不要无视一年级学生的情景。鞋柜=教室门窗，那么鞋柜中的鞋子或许就是那段情景的象征。
回忆过后，与之前“放手”的动作相对，优子的左手抓紧了从鞋柜中取出的鞋子，这双鞋子或许代表着她的选择与决心——既然香织可以为挽留一年级学生低头恳求学姐，甚至不惜放弃参赛资格，那么自己也能抛开学姐的身份去低头恳求丽奈让出独奏的位置。对于凭实力取胜感到无望的优子来说，这是她唯一能想到的办法。

![](/media/notes/504870376/p27537197.jpg)

夏纪的突然接近让优子在惊慌中丢掉了鞋子。夏纪忠告优子别动歪脑筋，那只会让香织伤心，此时优子的手抽动了一下，夏纪看穿了她的心思，也戳中了这个选择的痛处。
场景最后，镜头对准了优子的双脚与一旁掉在地上的鞋子——优子明白夏纪所说的话，她知道那样做会伤害和侮辱香织，甚至会被香织讨厌，但无论如何都想让香织担任独奏的她不得不去捡起那双鞋子。鞋子在这段场景中是象征优子的想法与决心的小道具。

![](/media/notes/504870376/p27537206.jpg)

丽奈没有明确回绝优子的请求，优子的举动与话语确实让原本就有所犹豫的丽奈产生了动摇。选拔前优子扑向夏纪的场景从优子的脚步（鞋子）特写开始引入，短暂的依靠后，优子再次迈步向前——此时的她或许正感到不安，但绝没有后悔。
【栏杆，久美子与秀一】

![](/media/notes/504870376/p27537210.jpg)

第四集中用来表现久美子与丽奈之间存在障碍的栏杆，这次用在了久美子与秀一之间。本集将秀一恋情的不顺与练习的不顺关联到了一起，那么在大赛开始前，两人的关系应该会得到改善。
【光影，久美子与丽奈】

![](/media/notes/504870376/p27537213.jpg)

从阴影迈向光明的一步。丽奈在久美子的支持下扫去了心中的不安与犹豫，重新变回焕发光辉、为久美子所憧憬的丽奈。
丽奈被优子的恳求所动摇，害怕成为恶人的她在久美子面前显露出了柔弱的一面。超然的她也有着常人的弱点，也是个有血有肉、有着普通人的情感的高中女孩。
这段场景中的对话与第八集中的“爱与死”相呼应。与第八集相反，这次是久美子对丽奈的“告白”，是两人关系的再确认。至此，久美子与丽奈之间的关系发展及其成果已经得到了较为圆满的描写，故事正渐入尾声。
【各自的理解者】

![](/media/notes/504870376/p27537218.jpg)

选拔前久美子与叶月和小绿之间无声的默契。正如ED中久美子与丽奈之间有着叶月与小绿的牵线搭桥，两人从一开始就是推动久美子接近丽奈的助力者。

![](/media/notes/504870376/p27537221.jpg)

从优子迈步奔向夏纪开始，到接下来的香织与晴香，直至最后的丽奈与久美子——这三段两人场景中连贯的背景音乐宛如一曲人情美的赞歌，串连起了这三对知心朋友。
丽奈的身后有久美子，久美子的身后有叶月和小绿，香织的身后有晴香和优子，优子的身后有夏纪——这应该是本集最大的魅力，她们每个人的背后都有理解者与支持者。
【香织vs丽奈】

![](/media/notes/504870376/p27537222.jpg)

丽奈与香织拿起各自的乐器包，朝着相反的方向走去。一硬一软的两种乐器包符合两人截然相反的性格特征。

![](/media/notes/504870376/p27537224.jpg)

演奏前香织在确认运指动作，吹之前嘴唇还在颤抖，与自信的丽奈形成对比。

![](/media/notes/504870376/p27537225.jpg)

演奏时的拉远镜头表现了乐声响彻的范围。香织吹奏时镜头只是缓缓拉到会场中部，而丽奈吹奏时镜头一下子拉到了会场最后方，显然丽奈的号声能够响彻整个会场。
响彻范围是这两段独奏最根本的区别，上集中的毛毯是本集的伏笔，泷老师将这场选拔安排在音乐厅进行的用意也在于此。

![](/media/notes/504870376/p27537227.jpg)

香织演奏时大家基本上都闭着眼睛仔细聆听，镜头只聚焦了几个主要人物。而丽奈演奏时镜头拍摄了更多的观众，包括明日香在内的大多数人都惊讶地睁开了眼睛——其中观众席的第一个上移镜头重点描写了四名三年级学生（绿领巾）震惊的表情。
有几个一年级学生（粉红领巾）并没有睁开眼睛，作为新手的她们应该无法明显地感觉到这两段演奏的区别，叶月就是其中一人，这个描写非常真实。

![](/media/notes/504870376/p27537236.jpg)

演奏后秀一身旁的男生前后两次的表情对比。丽奈演奏结束后，显然他正在对自己前一次的拍手叫好感到尴尬和惭愧。

![](/media/notes/504870376/p27537238.jpg)

拍手表决时，之前那四名三年级学生面露难色。虽然她们清楚地感受到了两者的差距，但高年级学生明白香织曾经的付出与牺牲，对她们来说这是一个两难的选择。

![](/media/notes/504870376/p27537239.jpg)

香织的表情变化。先是被优子的起立拍手感动，接着是对明日香没有拍手感到失落，最后又对晴香的拍手感到欣慰。渴望得到明日香的认同的香织，在明日香没有拍手的此刻，应该已经获得了自己所能彻底接受的答案。

![](/media/notes/504870376/p27537242.jpg)

久美子的掌声比起优子节奏更快更响亮。久美子的这个举动也与第二集中两次都没举手的她形成了鲜明的对比，曾经意志薄弱的久美子如今已经能对自己坚信的事物勇敢地站出来表态，这是她与丽奈走到一起后收获的成长。

![](/media/notes/504870376/p27537243.jpg)

站在会场中间的泷老师在这场对决中始终保持着中立。拍手表决平局后，泷老师将决定权交给了这场对决的发起人香织。“音乐无法让人说谎”，这个问题考验的是香织对音乐的诚挚，微笑的泷老师相信香织会做出正确的选择。
香织依旧是那个喜爱音乐的温柔学姐——香织的回答也让优子彻底接受了香织无法担任独奏的现实，能为他人如此痛哭的优子与香织一样是个值得尊敬、惹人怜爱的人物。
